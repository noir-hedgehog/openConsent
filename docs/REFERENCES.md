# Primary references

Rule packs should cite primary sources directly and record the date reviewed. These links are a starting register, not an exhaustive legal bibliography.

## GDPR and European privacy

- [GDPR official text, EUR-Lex](https://eur-lex.europa.eu/eli/reg/2016/679/oj)
- [EDPB Guidelines 05/2020 on consent](https://www.edpb.europa.eu/our-work-tools/our-documents/guidelines/guidelines-052020-consent-under-regulation-2016679_en)
- [EDPB Guidelines 3/2022 on dark patterns in social media platform interfaces](https://www.edpb.europa.eu/our-work-tools/our-documents/guidelines/guidelines-032022-deceptive-design-patterns-social-media_en)
- [ePrivacy Directive current text, including Article 5(3), EUR-Lex](https://eur-lex.europa.eu/eli/dir/2002/58/2009-12-19/eng)
- [EDPB Cookie Banner Taskforce report](https://www.edpb.europa.eu/system/files/2023-01/edpb_20230118_report_cookie_banner_taskforce_en.pdf)
- [European Commission data protection overview](https://commission.europa.eu/law/law-topic/data-protection/data-protection-eu_en)

ePrivacy rules and each relevant member-state implementation must be assessed separately for cookies and similar technologies.

## AI transparency (optional future pack)

- [EU AI Act consolidated text dated 2026-07-27, EUR-Lex](https://eur-lex.europa.eu/eli/reg/2024/1689/2026-07-27/eng)
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework)

AI-created code alone does not establish that the deployed product is an AI system under a particular law. The creation method and runtime AI functionality remain separate manifest fields.

## Reference project

- [ConsentStack/CMP repository](https://github.com/ConsentStack/cmp) — reviewed at commit `0eca47167a3823fc9063f2fe54806a73517234d9`. Its MIT-licensed source was inspected for concepts and implementation risks; openConsent contains a new implementation and does not copy that code. ConsentStack's root `LICENSE`/README state MIT while its historical `package.json` says ISC, so any future reuse needs a deliberate licence review.
