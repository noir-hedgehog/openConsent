# Security policy

openConsent is pre-alpha. Do not use it as the sole control for production personal data or agent authorisation.

Until maintainers enable GitHub private vulnerability reporting or publish a monitored security address, contact the repository owner privately through GitHub without publishing exploit details. Enabling a durable private reporting channel is a release blocker for the first alpha.

Include the affected version, reproduction steps, impact, and suggested mitigation. Do not include personal data, credentials, access tokens, or live customer evidence. Maintainers should acknowledge a valid report within three business days and publish a coordinated advisory after a fix is available.
